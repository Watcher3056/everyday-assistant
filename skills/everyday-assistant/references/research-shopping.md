# Research, Shopping, Places

## Research scope

- Answer exactly what was asked. If the user wants accommodation options in given towns, list listings with prices, not a logistics analysis of districts.
- Use the real browser for current prices and availability. Don't filter by stale brackets like "headphones under $100": prices depend on region and year, so check them manually.
- Before saying "nothing better exists", widen the search: niche local sites, marketplaces, direct sellers.

## Product identity

- **Exact item:** model, variant, size, color, compatibility (e.g. lid diameter, gas type). Say which variant a listing actually is when similar models differ.
- **Seller:** reputation, condition (new/used), live stock, delivery date, total price including delivery.
- **Region:** shops in the user's country by default (its main marketplaces, price aggregators and specialist shops). Other countries only when asked.
- **Links:** open every link before giving it. It must lead to that exact item and work. Dead or wrong links are a top frustration.

## Reviews

- Show the rating **and** the number of reviews **and** the source(s). When the user asks for quality, the default threshold is ≥4.5.
- Base pros and cons on real user reports, not only on specs. Report recurring real defects (e.g. "battery dies early, many Reddit complaints").

## Comparison tables

- **Use a table for more than 2 items.**
- **First column:** the name as a clickable link (shop page; for places, a Google Maps pin).
- **Columns:** rating with review count, an overall recommendation score for this user's context, price in **one currency** everywhere.
- **Pictures:** a photo of each item next to it, aspect ratio kept, no stretched images.
- **Completeness:** never drop columns or criteria to look brief. Explain flagged values (⚠️) in the table or right under it.
- **Files:** for xlsx/html, make sure sorting, filters and toggles actually work, and use a modern, readable design.
- **End with one recommended choice and why,** plus alternatives for "if X matters more".
- **Sub-agent (when available):** with several candidates, verify each one in parallel: working link to the exact item, live price and stock, delivery, rating with count, recurring complaints, etc. Combine the results and pick the recommendation yourself.

## Presentations and catalogs (when asked)

Mobile-friendly, the theme the user asked for, enough information per option to decide (not a minimal stub), and real photos.

## Places and accommodation

- **Names:** refer to options and rooms by their real names.
- **Prices:** say what a price is per (person/night vs room/night) and check it on the page.
- **Availability:** "confirmed available" vs "unknown, request needed".
- **Booking:** how to book and pay (site form, email, on-site cash/card).
- **Trips:** practical access, i.e. distance to the target activity and transport by the means of travel the user has (SKILL.md, User context).
